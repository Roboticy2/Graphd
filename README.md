# Graphd

Graphd is a project intended to be for networks what Tiled is for tile maps for game developers. My primary interest is dialogue trees, but networks have many other applications including behaviors, shaders, and animation which could be interesting to explore.

# Format

Graphs created by Graphd can be exported to dot format, which can be visualized using the [graphviz](https://graphviz.org/) library or in-text using [Graph::Easy](https://metacpan.org/pod/Graph::Easy). 

# Examples

The main access point for new users is the examples folder, which shows off features as primitive as basic visualization, all the way to full tooling using the program.
